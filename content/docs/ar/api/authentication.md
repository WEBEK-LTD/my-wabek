# المصادقة

تُصادَق كل طلبات الـ API بمفتاح API مرتبط بحسابك. كل مفتاح يمنح وصولًا كاملًا إلى نقاط الـ API لحسابك، فتعامل معه ككلمة مرور.

## العنوان الأساسي

```
https://waabek.com
```

> **ملاحظة:** إن كنت تستخدم [العلامة البيضاء](/docs/guides/white-label) بنطاق خاص، فتحقّق من العنوان الصحيح في صفحة **API Keys**؛ أمثلة الأوامر هناك تُبنى على النطاق الذي تفتح منه لوحة التحكم.

## الحصول على مفتاح

صفحة **API Keys** متاحة لصاحب الحساب فقط، وتتطلب باقة تتضمن **API Access**.

| نوع المفتاح | الوصف |
|---|---|
| **Default API Key** | مفتاح يُنشأ تلقائيًا مع الحساب. يمكنك إظهاره ونسخه من الصفحة. |
| **Named API Keys** | مفاتيح تنشئها بنفسك لكل تكامل، وتبدأ بـ `wbk_`. يظهر المفتاح **مرة واحدة فقط** عند إنشائه. |

لإنشاء مفتاح مسمّى:

1. افتح **API Keys** واضغط **New Key**.
2. أدخل اسمًا يصف الاستخدام، مثل `WooCommerce Production`.
3. اضغط **Create Key** وانسخ المفتاح فورًا واحفظه في مكان آمن.

> **تحذير:** استخدم مفتاحًا مسمّى مستقلًا لكل تكامل. عندها يمكنك إلغاء مفتاح واحد مسرّب دون تعطيل بقية تكاملاتك. يعرض كل مفتاح تاريخ آخر استخدام.

لإلغاء مفتاح اضغط أيقونة الحذف بجانبه. يتوقف المفتاح عن العمل فورًا.

## إرسال المفتاح

أرسل المفتاح في **ترويسة** الطلب بإحدى الطريقتين:

```
X-API-Key: YOUR_API_KEY
```

```
Authorization: Bearer YOUR_API_KEY
```

مثال:

```bash
curl https://waabek.com/api/v1/contacts \
  -H "X-API-Key: $WABEK_API_KEY"
```

## المفتاح في الرابط (مُهمَل)

للتوافق مع التثبيتات القديمة، ما زالت بعض النقاط تقبل المفتاح في الرابط (`?api_key=` أو `?key=`)، وتقبل نقطة البوابة أيضًا `api_key` في جسم الطلب.

> **تحذير:** هذه الطريقة **مُهمَلة** وقد تُعطَّل دون إشعار مسبق. الروابط تُحفظ في سجلات الخوادم والمتصفحات وأدوات المراقبة، فيسهل تسريب المفتاح. انقل تكاملاتك إلى الترويسة. عند استلام مفتاح في الرابط تسجّل المنصة تحذيرًا.

## الدعم حسب النقطة

| النقطة | `X-API-Key` | `Authorization: Bearer` | `?api_key=` (مُهمَل) |
|---|---|---|---|
| `/api/v1/*` | ✅ | ✅ | ✅ |
| `/api/gateway/whatsapp` | ✅ | ✅ | ✅ (وكذلك `api_key` في الجسم) |
| `/api/webhooks/wix` | ✅ | ✅ | ✅ |
| `/api/webhooks/trigger` | ✅ | ❌ | ❌ |

## الاستجابة عند فشل المصادقة

```json
{ "error": "Invalid API key" }
```

الحالة HTTP: `401`. تحقّق من أن المفتاح منسوخ كاملًا دون مسافات، وأنه لم يُلغَ، وأن الحساب فعّال.

## CORS

نقاط `/api/v1/*` و`/api/gateway/whatsapp` تسمح بطلبات من أي مصدر، لكن **لا تستدعِها من متصفح المستخدم**؛ سيصبح مفتاحك مكشوفًا لكل زائر. استدعِ الـ API من خادمك. راجع [أمان المفاتيح](/docs/security/api-keys).
