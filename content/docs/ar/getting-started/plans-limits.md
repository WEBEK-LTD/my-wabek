# الباقات والحدود

تختلف الأسعار والحدود من باقة إلى أخرى، وتظهر تفاصيل باقتك الحالية في صفحة **Billing**. هذه الصفحة تشرح **كيف** تعمل الحدود، لا قيمها.

## الحدود الكمّية

| الحد | طريقة الاحتساب | عند بلوغه |
|---|---|---|
| الرسائل الشهرية | كل رسالة صادرة من حسابك منذ بداية الشهر الميلادي (من صندوق الوارد، والحملات، والـ API، والأتمتة) | يُرفض الإرسال برمز `plan_limit` |
| الحملات الشهرية | الحملات المُنشأة منذ بداية الشهر | يُرفض إنشاء حملة جديدة مع رسالة تطلب الترقية |
| أرقام واتساب | عدد الأرقام المربوطة | يُمنع ربط رقم جديد؛ الأرقام الحالية لا تتأثر |
| ردود الذكاء الاصطناعي | ردود المساعد الآلي هذا الشهر | يتوقف الرد الآلي حتى بداية الشهر التالي |
| أعضاء الفريق، تدفقات الشات بوت، الردود السريعة، الشرائح، الروابط، الحسابات الفرعية | حسب الباقة | حسب الباقة |

> **ملاحظة:** القيمة `-1` في باقة تعني بلا حد. لردود الذكاء الاصطناعي تحديدًا، القيمة `0` تعني أن الميزة غير متاحة في الباقة.

## الميزات حسب الباقة

بعض الصفحات لا تظهر إلا إذا كانت باقتك تتضمنها:

| الميزة | تتحكم في |
|---|---|
| API Access | صفحتا **API Keys** و**Integrations** |
| Chatbot | منشئ الشات بوت |
| Automation | صفحة **Flows** |
| Analytics | صفحة التحليلات |
| White Label | العلامة البيضاء |
| Sub-Accounts | الحسابات الفرعية |
| Reseller | نظام الموزّعين |

إذا فتحت صفحة غير متاحة في باقتك تظهر شاشة **Upgrade**.

## انتهاء الباقة أو الفترة التجريبية

عند انتهاء الاشتراك أو الفترة التجريبية **لا يُغلق الحساب**، بل تُطبّق عليه حدود الباقة المجانية وميزاتها تلقائيًا إلى أن تجدّد.

## الترقية

1. افتح **Billing**.
2. اختر الدورة: شهرية أو سنوية (إن توفرت).
3. اضغط على الباقة المطلوبة وأكمل الدفع.

راجع [الفوترة](/docs/guides/billing) لإدارة الاشتراك وأكواد الهدايا.

## استجابة الـ API عند بلوغ الحد

```json
{
  "error": "Monthly message limit reached for your plan",
  "code": "plan_limit"
}
```

الحالة HTTP: `403`. راجع [الأخطاء ورموزها](/docs/api/errors).
