# ربط رقم واتساب

تدعم WABEK طريقتين لربط الرقم. اختر الطريقة قبل البدء، لأنها تحدّد كيف تُرسل الرسائل وما القيود المطبّقة.

## المقارنة

| | Cloud API الرسمي (Meta) | واتساب ويب (QR) |
|---|---|---|
| **الجهة المشغّلة** | واجهة Meta الرسمية للأعمال | جلسة واتساب ويب مرتبطة بهاتفك |
| **المتطلبات** | حساب Meta Business وحساب واتساب للأعمال (WABA) | هاتف عليه واتساب أو واتساب للأعمال |
| **نافذة الـ 24 ساعة** | مطبّقة: خارجها يلزم قالب معتمد | لا تُطبّق قواعد القوالب |
| **الحملات** | تُرسل دائمًا عبر قالب معتمد | تُرسل كنص عادي |
| **رموز التحقق (OTP)** | عبر قالب من فئة Authentication | نص عادي |
| **مخاطر الحظر** | منخفضة ما دمت تلتزم بسياسات Meta | **مرتفعة** عند الإرسال الجماعي أو للأرقام غير المحفوظة |
| **الاستقرار** | لا يعتمد على هاتفك | يتطلب بقاء الجلسة متصلة؛ قد تنقطع وتحتاج إعادة مسح |
| **التكلفة لدى Meta** | تفرض Meta رسومها الخاصة على بعض فئات الرسائل | لا رسوم من Meta |

> **تحذير:** واتساب ويب ليس قناة رسمية للأعمال. الإرسال الجماعي أو المتكرّر عبره يخالف شروط واتساب وقد يؤدي إلى **حظر الرقم نهائيًا**. استخدمه للمحادثات الفردية مع عملاء يعرفونك، واستخدم Cloud API للحملات والإشعارات.

## الطريقة 1: Cloud API عبر Meta (موصى بها)

### الربط التلقائي (Embedded Signup)

1. من لوحة التحكم افتح **WhatsApp** ثم تبويب **Cloud API**.
2. اضغط **Connect with Meta**.
3. سجّل الدخول إلى Facebook، ثم اختر (أو أنشئ) حساب Meta Business وحساب واتساب للأعمال.
4. اختر رقم الهاتف أو أضف رقمًا جديدًا وأكّده برمز SMS أو مكالمة.
5. أكمل النافذة. عند النجاح تظهر رسالة **WhatsApp connected** ويظهر الرقم في القائمة بحالة **connected**.

### الإعداد اليدوي (للمستخدمين المتقدمين)

استخدمه إذا كان لديك تطبيق Meta وبيانات الرقم جاهزة.

1. اضغط **Manual Setup**.
2. املأ الحقول:

| الحقل | المصدر |
|---|---|
| Phone Number (E.164) | رقمك بالصيغة الدولية، مثل `+9665XXXXXXXX` |
| Phone Number ID | من Meta Developer Portal ← WhatsApp ← API Setup |
| WABA ID | معرّف حساب واتساب للأعمال |
| Access Token | رمز **System User** دائم بصلاحيتي `whatsapp_business_messaging` و`whatsapp_business_management` |

3. اضغط **Connect**.

> **تحذير:** لا تستخدم الرمز المؤقت (Temporary Token) من Meta Developer Portal؛ تنتهي صلاحيته خلال ساعات وتتوقف بعدها الرسائل الواردة والصادرة.

بعد الربط يعرض كل رقم **Instance ID** و**Phone Number ID** و**Webhook URL**. انسخ **Instance ID** إن احتجت إلى تحديد الرقم في طلبات الـ API.

### قبل الإرسال عبر Cloud API

- أنشئ قوالبك في Meta Business Manager وانتظر اعتمادها (الحالة `APPROVED`).
- تظهر القوالب المعتمدة تلقائيًا عند إنشاء حملة.
- راجع [نافذة الـ 24 ساعة والقوالب](/docs/getting-started/messaging-window).

## الطريقة 2: واتساب ويب عبر رمز QR

1. افتح **WhatsApp** ثم تبويب **WhatsApp Web**.
2. اضغط **Connect via QR Code**. يظهر رمز QR خلال ثوانٍ.
3. على هاتفك افتح واتساب ← **الأجهزة المرتبطة** ← **ربط جهاز**، ثم امسح الرمز.
4. تتحدّث الصفحة تلقائيًا. عند النجاح تتغيّر الحالة إلى **connected** ويظهر رقمك.

> **ملاحظة:** رمز QR صالح لفترة قصيرة. إذا انتهت صلاحيته اضغط **Show QR Code** أو **Reconnect** لتوليد رمز جديد.

### الحفاظ على الجلسة

- أبقِ الهاتف متصلًا بالإنترنت، ولا تسجّل الخروج من الأجهزة المرتبطة.
- إذا أصبحت الحالة **disconnected** فاضغط **Reconnect** وامسح الرمز مجددًا.

## عدد الأرقام

يعتمد عدد الأرقام التي يمكنك ربطها على باقتك. إذا بلغت الحد تظهر رسالة تطلب الترقية، ولا تتأثر الأرقام المربوطة مسبقًا. راجع [الباقات والحدود](/docs/getting-started/plans-limits).

## حذف رقم

اضغط أيقونة سلة المهملات بجانب الرقم. يتوقف الإرسال والاستقبال عبره فورًا داخل WABEK.
