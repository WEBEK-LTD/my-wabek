# نظرة عامة

WABEK منصة لإدارة مراسلات واتساب للأعمال. تربط من خلالها رقم واتساب واحدًا أو أكثر، ثم تستقبل المحادثات وتردّ عليها مع فريقك، وترسل الحملات، وتبني الشات بوت والأتمتة، وتربط متجرك أو نظامك بواجهة برمجة التطبيقات (API).

## المفاهيم الأساسية

| المفهوم | المعنى |
|---|---|
| **الرقم (Instance)** | رقم واتساب مربوط بحسابك. لكل رقم معرّف `instance_id` يظهر في صفحة **WhatsApp** داخل لوحة التحكم. |
| **نوع الاتصال** | إما **Cloud API الرسمي** من Meta، أو **واتساب ويب** عبر رمز QR. يحدّد النوع طريقة الإرسال والقيود المطبّقة. راجع [ربط رقم واتساب](/docs/getting-started/connect-number). |
| **جهة الاتصال** | عميل محفوظ برقم هاتفه، مع اسم وبريد ووسوم (Tags) اختيارية. |
| **المحادثة** | سلسلة الرسائل بينك وبين جهة اتصال على رقم معيّن، وتظهر في صندوق الوارد. |
| **نافذة الـ 24 ساعة** | مدة تبدأ من آخر رسالة أرسلها العميل إلى رقمك. داخلها يمكنك إرسال نص حر، وخارجها يلزم قالب معتمد من Meta (لأرقام Cloud API). راجع [نافذة الـ 24 ساعة والقوالب](/docs/getting-started/messaging-window). |
| **القالب (Template)** | رسالة مسجّلة ومعتمدة مسبقًا في Meta Business Manager، تُستخدم لبدء المحادثة أو لإرسال الحملات. |
| **مفتاح API** | سرّ يربط أنظمتك الخارجية بحسابك، ويُرسل في ترويسة الطلب. راجع [المصادقة](/docs/api/authentication). |

## ماذا يمكنك أن تفعل؟

- **التواصل اليومي:** صندوق وارد مشترك للفريق مع إسناد المحادثات وحالاتها. راجع [صندوق الوارد والفريق](/docs/guides/inbox).
- **الرسائل الجماعية:** حملات فورية أو مجدولة لجهات الاتصال حسب الوسوم. راجع [الحملات](/docs/guides/campaigns).
- **الرد الآلي:** شات بوت مرئي، وأتمتة بالكلمات المفتاحية، ومساعد ذكاء اصطناعي. راجع [الشات بوت](/docs/guides/chatbot).
- **التكامل:** WordPress/WooCommerce وWHMCS وWix وZapier، أو واجهة API مباشرة. راجع [التكاملات](/docs/integrations/wordpress).
- **إعادة البيع:** علامة بيضاء، وحسابات فرعية، ونظام موزّعين.

## العنوان الأساسي

جميع طلبات الـ API تُرسل إلى:

```
https://waabek.com
```

> **ملاحظة:** إن كنت تستخدم نطاقًا خاصًا عبر [العلامة البيضاء](/docs/guides/white-label)، فتحقّق من العنوان الفعلي لحسابك في صفحة **API Keys** داخل لوحة التحكم؛ أمثلة الأوامر هناك تُبنى على النطاق الذي تفتح منه اللوحة.
