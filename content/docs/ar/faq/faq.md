# الأسئلة الشائعة

## هل أستخدم Cloud API أم واتساب ويب؟

استخدم **Cloud API** لأي نشاط تجاري جاد، خاصة الحملات والإشعارات الآلية. استخدم **واتساب ويب** فقط للمحادثات الفردية إذا لم تتمكن من استخدام Cloud API، مع إدراك خطر الحظر. راجع [ربط رقم واتساب](/docs/getting-started/connect-number).

## هل يمكنني استخدام الرقم نفسه على هاتفي وفي Cloud API معًا؟

الرقم المسجّل في Cloud API لا يعمل عادةً في تطبيق واتساب العادي على الهاتف في الوقت نفسه. راجع خيارات Meta الحالية قبل نقل رقم مستخدم. أما واتساب ويب فيعمل مع هاتفك كجهاز مرتبط.

## لماذا لم تصل رسالتي رغم نجاح الطلب؟

الاستجابة `200` تعني أن الرسالة قُبلت للإرسال، لا أنها سُلّمت. قد ترفضها Meta لاحقًا (مثل رقم غير موجود على واتساب). تابع حالة الرسالة في صندوق الوارد. راجع [استكشاف الأخطاء](/docs/faq/troubleshooting).

## هل يمكنني إرسال صور أو ملفات عبر الـ API؟

نقاط الـ API العامة الحالية ترسل نصًا فقط. يمكن إرسال المرفقات (حتى 16 ميغابايت) من صندوق الوارد.

## هل تدعم القوالب العربية؟

حاليًا تُرسل WABEK القوالب برموز اللغة الإنجليزية فقط: `en` في الحملات، و`en` ثم `en_US` في `POST /api/v1/send`، و`en` و`en_US` و`en_GB` لرموز التحقق. القالب المعتمد في Meta برمز اللغة `ar` وحده لن يُعثر عليه في هذه المسارات، وستعيد Meta الخطأ `132001`.

## كم رسالة يمكنني إرسالها؟

حسب باقتك (حد شهري للرسائل)، وحسب حدود Meta لرقمك على Cloud API. راجع [الباقات والحدود](/docs/getting-started/plans-limits) و[حدود المعدّل](/docs/api/rate-limits).

## ماذا يحدث لبياناتي إذا انتهى اشتراكي؟

لا تُحذف. تُطبّق حدود الباقة المجانية حتى تجدّد.

## هل يرى أعضاء الفريق مفتاح الـ API؟

لا. إدارة المفاتيح وعرضها متاحة لصاحب الحساب فقط.

## كيف أوقف المساعد الآلي لعميل محدد؟

من صفحة جهة الاتصال اضغط **Disable AI**. يتوقف المساعد تلقائيًا أيضًا إذا كتب العميل إحدى كلمات التصعيد. راجع [مساعد الذكاء الاصطناعي](/docs/guides/ai-assistant).

## هل توقّع WABEK إشعارات الـ Webhook؟

ليس في هذا الإصدار. أمّن نقطتك برمز سري في الرابط. راجع [Webhooks الصادرة](/docs/api/outgoing-webhooks).

## أين أجد Instance ID؟

في صفحة **WhatsApp**، على بطاقة كل رقم، مع زر نسخ.
