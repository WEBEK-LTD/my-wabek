# WHMCS

ترسل وحدة WABEK لـ WHMCS إشعارات واتساب لعملائك عند أحداث الفوترة والدعم الفني والخدمات.

## المتطلبات

- صلاحية مدير على WHMCS ووصول إلى ملفات الخادم.
- رقم واتساب متصل في WABEK.
- مفتاح API من حسابك (تتطلب صفحة المفاتيح باقة تتضمن **API Access**).

## 1. التثبيت

1. نزّل الوحدة من:

   ```
   https://waabek.com/downloads/wabek-whmcs-addon.zip
   ```

   أو من **Integrations** ← تبويب **Modules** داخل لوحة التحكم.
2. فك الضغط وارفع المجلد إلى `modules/addons/` في مجلد WHMCS. <!-- verify against plugin -->
3. في WHMCS افتح **System Settings ← Addon Modules**، وابحث عن WABEK، واضغط **Activate**. <!-- verify against plugin -->
4. اضغط **Configure**، وامنح الصلاحية لمجموعات المدراء المطلوبة، ثم احفظ.

## 2. الربط بحسابك

1. في WABEK افتح **API Keys** واضغط **New Key**، وسمِّه مثلًا `WHMCS Production`.
2. انسخ المفتاح فورًا؛ لن يظهر مرة أخرى.
3. في إعدادات الوحدة داخل WHMCS الصق المفتاح في حقل **API Key**. <!-- verify against plugin -->
4. اضغط **اختبار الاتصال** (Test Connection) وتأكّد من ظهور رسالة نجاح. <!-- verify against plugin -->

> **ملاحظة:** ترسل الوحدة المفتاح في ترويسة الطلب. لا تستخدم روابط قديمة تحتوي على `?api_key=` في الرابط.

## 3. اختيار الرقم

اختر الرقم المرسِل من الإعدادات إذا كان لديك أكثر من رقم. <!-- verify against plugin -->

## 4. تفعيل الأحداث

فعّل الأحداث المطلوبة، مثل: <!-- verify against plugin -->

| الحدث | مثال |
|---|---|
| إنشاء فاتورة | إبلاغ العميل بفاتورة جديدة ورابط الدفع |
| دفع فاتورة | تأكيد استلام الدفعة |
| فاتورة متأخرة / تذكير دفع | تذكير قبل أو بعد تاريخ الاستحقاق |
| فتح تذكرة / رد على تذكرة | إبلاغ العميل بتحديثات الدعم |
| تفعيل خدمة / تعليق خدمة | إبلاغ العميل بحالة الخدمة |

## 5. قوالب الرسائل

لكل حدث نص قابل للتعديل يدعم متغيرات الدمج، مثل: <!-- verify against plugin -->

| المتغير | القيمة |
|---|---|
| `{client_name}` | اسم العميل |
| `{invoice_id}` | رقم الفاتورة |
| `{invoice_total}` | مبلغ الفاتورة |
| `{due_date}` | تاريخ الاستحقاق |
| `{ticket_id}` | رقم التذكرة |
| `{service_name}` | اسم الخدمة |

مثال:

```
مرحبًا {client_name}، صدرت الفاتورة رقم {invoice_id} بمبلغ {invoice_total}، وتستحق في {due_date}.
```

## رقم هاتف العميل

يُرسل الإشعار إلى رقم الهاتف في ملف العميل على WHMCS. تأكّد من حفظ الأرقام بالصيغة الدولية مع رمز الدولة.

## نافذة الـ 24 ساعة

إشعارات الفواتير تُرسل غالبًا لعملاء لم يراسلوك مؤخرًا. على أرقام **Cloud API** يلزم قالب معتمد من Meta لهذه الحالات. راجع [نافذة الـ 24 ساعة](/docs/getting-started/messaging-window).

## الطريقة القديمة (Webhook)

إذا كنت تستخدم رابط Webhook قديمًا بالشكل `/api/v1/whmcs-webhook?api_key=...`، فانتقل إلى الوحدة الجديدة. إرسال المفتاح في الرابط **مُهمَل** وقد يُعطَّل. راجع [WHMCS Webhook](/docs/api/whmcs-webhook).

## استكشاف الأخطاء

| العَرَض | السبب المحتمل |
|---|---|
| 401 عند الاختبار | المفتاح خاطئ أو أُلغي |
| 404 | لا يوجد رقم متصل في حسابك |
| 403 | بلغت حد الرسائل، أو العميل محظور أو ألغى اشتراكه |
| 422 | العميل خارج نافذة الـ 24 ساعة ولا يوجد قالب صالح |
