# WordPress وWooCommerce

ترسل إضافة WABEK لـ WordPress إشعارات واتساب لعملائك عند أحداث متجر WooCommerce، مثل إنشاء الطلب أو تغيّر حالته.

## المتطلبات

- موقع WordPress مع صلاحية تثبيت الإضافات.
- WooCommerce مفعّل (لإشعارات الطلبات).
- رقم واتساب متصل في WABEK.
- مفتاح API من حسابك (تتطلب صفحة المفاتيح باقة تتضمن **API Access**).

## 1. التثبيت

1. نزّل الإضافة من:

   ```
   https://waabek.com/downloads/wabek-wordpress-plugin.zip
   ```

   أو من **Integrations** ← تبويب **Modules** داخل لوحة التحكم.
2. في لوحة WordPress افتح **الإضافات ← أضف جديد ← رفع إضافة**.
3. اختر الملف المضغوط واضغط **التثبيت الآن**، ثم **تفعيل**.

## 2. الربط بحسابك

1. في WABEK افتح **API Keys** واضغط **New Key**، وسمِّه مثلًا `WordPress - متجري`.
2. انسخ المفتاح فورًا؛ لن يظهر مرة أخرى.
3. في WordPress افتح صفحة إعدادات WABEK. <!-- verify against plugin -->
4. الصق المفتاح في حقل **API Key**. <!-- verify against plugin -->
5. اضغط **اختبار الاتصال** (Test Connection). يجب أن تظهر رسالة نجاح. <!-- verify against plugin -->

> **ملاحظة:** ترسل الإضافة المفتاح في ترويسة الطلب (`X-API-Key`)، ولا تضعه في الرابط.

## 3. اختيار الرقم

إذا كان لديك أكثر من رقم، اختر الرقم المرسِل من قائمة الأرقام في الإعدادات. <!-- verify against plugin --> إذا لم تختر رقمًا يُستخدم أول رقم متصل في حسابك.

## 4. تفعيل الأحداث

فعّل الأحداث التي تريد إرسال إشعار عندها، مثل: <!-- verify against plugin -->

| الحدث | مثال على الاستخدام |
|---|---|
| طلب جديد | تأكيد استلام الطلب |
| تغيّر حالة الطلب (قيد التنفيذ، مكتمل، ملغى…) | إبلاغ العميل بالتقدّم |
| ملاحظة للعميل | إرسال ملاحظة الطلب عبر واتساب |

## 5. قوالب الرسائل

لكل حدث نص قابل للتعديل يدعم متغيرات الدمج، مثل: <!-- verify against plugin -->

| المتغير | القيمة |
|---|---|
| `{customer_name}` | اسم العميل |
| `{order_id}` | رقم الطلب |
| `{order_total}` | إجمالي الطلب |
| `{order_status}` | حالة الطلب |
| `{site_name}` | اسم الموقع |

مثال:

```
مرحبًا {customer_name}، تم استلام طلبك رقم {order_id} بقيمة {order_total}. شكرًا لتسوّقك من {site_name}.
```

## نافذة الـ 24 ساعة

إذا كان رقمك على **Cloud API** وكان العميل لم يراسلك خلال آخر 24 ساعة، فلن يصله النص الحر. لإشعارات الطلبات خارج النافذة استخدم قالبًا معتمدًا من Meta إن كانت الإضافة تدعم ذلك، أو استخدم رقم واتساب ويب مع مراعاة مخاطر الحظر. راجع [نافذة الـ 24 ساعة](/docs/getting-started/messaging-window). <!-- verify against plugin -->

## رقم هاتف العميل

يُرسل الإشعار إلى رقم الهاتف في عنوان الفوترة للطلب. اطلب من عملائك إدخال الرقم بالصيغة الدولية مع رمز الدولة، أو اضبط رمز الدولة الافتراضي في الإعدادات إن توفّر. <!-- verify against plugin -->

## استكشاف الأخطاء

| العَرَض | السبب المحتمل |
|---|---|
| فشل اختبار الاتصال برمز 401 | المفتاح خاطئ أو أُلغي؛ أنشئ مفتاحًا جديدًا |
| فشل برمز 404 | لا يوجد رقم متصل في حسابك |
| فشل برمز 403 | بلغت حد الرسائل الشهري، أو العميل محظور أو ألغى اشتراكه |
| فشل برمز 422 | العميل خارج نافذة الـ 24 ساعة ولا يوجد قالب صالح |
| لا يصل أي إشعار | تحقق من تفعيل الحدث، ومن صحة رقم العميل |

المزيد في [الأخطاء ورموزها](/docs/api/errors).
