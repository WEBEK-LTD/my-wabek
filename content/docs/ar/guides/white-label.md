# العلامة البيضاء

تتيح العلامة البيضاء تقديم لوحة التحكم لعملائك باسم نشاطك وهويته البصرية وعلى نطاقك الخاص.

> **ملاحظة:** تتطلب هذه الميزة باقة تتضمن **White Label**.

## الهوية البصرية

افتح **White Label** واملأ قسم **Brand Identity**:

| الحقل | الوصف |
|---|---|
| Brand Name | الاسم الذي يظهر بدل WABEK |
| Logo URL | رابط `https://` للشعار |
| Primary Color | اللون الأساسي للأزرار والعناصر |
| Background Color | لون الخلفية |
| Favicon URL | رابط `https://` لأيقونة المتصفح |

## النطاق الخاص

1. أدخل النطاق في **Custom Domain**، مثل `app.example.com`.
2. لدى مزوّد النطاق أضف سجل DNS:
   - النوع: `CNAME`
   - الاسم: الجزء الفرعي (مثل `app`)
   - القيمة: القيمة المعروضة في صفحة **White Label**
3. احفظ الإعدادات، ثم اضغط **Check** للتحقق من DNS.

| النتيجة | المعنى |
|---|---|
| ✅ | السجل صحيح. يصبح النطاق فعالًا بعد اكتمال الانتشار |
| ⏳ | السجل لم ينتشر بعد؛ قد يستغرق ذلك حتى 48 ساعة |
| ❌ | النطاق غير موجود؛ راجع الكتابة وإعدادات DNS |

> **تحذير:** إن كنت تستخدم Cloudflare فاجعل السجل **DNS only** (السحابة الرمادية) وليس **Proxied**، وإلا تعذّر إصدار شهادة SSL.

لا يمكن استخدام نطاق مسجّل في حساب آخر.

## الدعم

أدخل **Support Email** و**Support WhatsApp** ليظهرا لعملائك بدل بيانات دعم WABEK.

## خيارات متقدمة

| الخيار | الوصف |
|---|---|
| Hide "Powered by WABEK" | يُخفي إشارة WABEK من التذييل |
| Custom CSS | قواعد CSS إضافية لتخصيص المظهر |
| Custom Footer Text | نص التذييل |

## واجهة الـ API على نطاقك

بعد تفعيل النطاق، يمكن لعملائك إرسال طلبات الـ API إلى نطاقك بدل `https://waabek.com`. تأكّد من العنوان من صفحة **API Keys**.
