# صندوق الوارد والفريق

صفحة **Live Chat** هي صندوق الوارد المشترك لكل أرقامك. تصل إليها الرسائل الواردة لحظيًا، ويستطيع أعضاء فريقك الرد منها.

## التنقّل بين الأرقام

إذا كان لديك أكثر من رقم، فلكل رقم صندوق وارد مستقل. اختر الرقم من قائمة الصناديق أعلى الصفحة. تتذكّر WABEK آخر صندوق فتحته.

## الرد على محادثة

1. اختر المحادثة من القائمة.
2. اكتب ردّك في مربع النص، أو أدرج **ردًا سريعًا** من زر الردود السريعة. راجع [الردود السريعة](/docs/guides/quick-replies).
3. لإرفاق ملف اضغط زر المرفقات. الحد الأقصى لحجم الملف **16 ميغابايت**.
4. اضغط **إرسال**.

> **ملاحظة:** على أرقام Cloud API، إذا كان العميل خارج نافذة الـ 24 ساعة فلن يُرسل النص الحر، وتظهر الرسالة «Outside 24h window — customer must message first». انتظر رسالة من العميل، أو تواصل معه عبر قالب معتمد. راجع [نافذة الـ 24 ساعة](/docs/getting-started/messaging-window).

## تنظيم المحادثات

| الخاصية | القيم |
|---|---|
| الحالة | `open` (مفتوحة)، `pending` (معلّقة)، `resolved` (محلولة)، `spam` (مزعجة) |
| الأولوية | `low`، `normal`، `high`، `urgent` |
| الإسناد | صاحب الحساب أو أي عضو في الفريق أو حساب فرعي تابع |
| الوسوم | قائمة نصية حرة |
| الملاحظات | ملاحظة داخلية حتى 5000 حرف، لا يراها العميل |

استخدم مرشّح الحالة أعلى القائمة لعرض المحادثات المفتوحة فقط (الافتراضي) أو أي حالة أخرى.

## العمل كفريق

1. ادعُ أعضاء فريقك من صفحة **Team**. راجع [الفريق والصلاحيات](/docs/guides/team-roles).
2. حدّد لكل عضو الصناديق (الأرقام) التي يمكنه الوصول إليها، أو اتركها فارغة ليصل إلى جميع الصناديق.
3. أسند المحادثة إلى العضو المسؤول عنها.

يتتبّع **Team ← Performance** الرسائل التي أرسلها كل عضو.

## حظر جهة اتصال

من صفحة جهة الاتصال اضغط **Block Contact**. يُرفض أي إرسال إلى جهة اتصال محظورة من صندوق الوارد والحملات ونقاط الـ API والتكاملات.
