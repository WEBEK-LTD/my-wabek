# تتبّع الروابط

أداة **Link Tracker** تنشئ رابطًا قصيرًا يحوّل الزائر إلى رابطك الأصلي ويسجّل كل نقرة.

## إنشاء رابط

1. افتح **Link Tracker** واضغط إنشاء.
2. أدخل **الرابط الأصلي**. يجب أن يبدأ بـ `http://` أو `https://`.
3. أدخل عنوانًا وصفيًا (اختياري)، واربطه بحملة (اختياري).
4. احفظ. يظهر الرابط القصير بالشكل:

```
https://waabek.com/l/Ab3xK9
```

5. انسخ الرابط القصير وضعه في رسالتك أو حملتك.

## قراءة النتائج

تعرض الصفحة عدد النقرات لكل رابط. يُسجَّل مع كل نقرة وقتها ومتصفح الزائر وعنوان IP الخاص به.

## قواعد

- الروابط غير الصالحة أو المحذوفة تحوّل الزائر إلى الصفحة الرئيسية.
- لا تُقبل روابط بغير بروتوكولي `http` و`https`.
- عدد الروابط المتاحة يعتمد على باقتك.

> **ملاحظة:** تسجيل عنوان IP ومعلومات المتصفح بيانات شخصية في بعض الأنظمة القانونية. اذكر استخدامك لتتبّع النقرات في سياسة الخصوصية الخاصة بنشاطك.
