# الفوترة

تعرض صفحة **Billing** باقتك الحالية وحدودها وتاريخ تجديدها، وتتيح الترقية وإدارة الاشتراك.

## الاشتراك أو الترقية

1. افتح **Billing**.
2. اختر **Monthly** أو **Yearly** (يظهر الخيار السنوي إن كان متاحًا للباقات).
3. اضغط على الباقة المطلوبة. تنتقل إلى صفحة دفع آمنة عبر Stripe.
4. أكمل الدفع. تعود إلى WABEK وتظهر رسالة تأكيد التفعيل.

الأسعار حسب الباقة والدورة، وتظهر في الصفحة قبل الدفع.

> **ملاحظة:** إذا سجّلت عبر رابط موزّع، فقد تظهر لك باقات الموزّع وأسعاره، وقد يتم الدفع إلى حساب الموزّع مباشرة.

## إدارة الاشتراك

اضغط زر إدارة الاشتراك لفتح بوابة Stripe، حيث يمكنك تحديث بطاقة الدفع، وتنزيل الفواتير، وإلغاء الاشتراك.

## أكواد الهدايا

1. اضغط **Have a gift code? Redeem here**.
2. أدخل الكود واضغط **Redeem**.
3. تُفعَّل الباقة المرتبطة بالكود للمدة المحددة فيه.

## عند انتهاء الاشتراك

لا يُحذف حسابك ولا بياناتك. تُطبّق حدود الباقة المجانية وميزاتها حتى تجدّد. راجع [الباقات والحدود](/docs/getting-started/plans-limits).

> **ملاحظة:** رسوم Meta على رسائل Cloud API (إن وُجدت) منفصلة عن اشتراك WABEK، وتُدفع لـ Meta عبر حساب واتساب للأعمال الخاص بك.
