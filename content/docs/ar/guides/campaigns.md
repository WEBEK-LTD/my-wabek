# الحملات

الحملة رسالة واحدة تُرسل إلى مجموعة من جهات الاتصال، فورًا أو في موعد محدّد.

> **تحذير:** أرسل الحملات فقط إلى عملاء وافقوا على تلقي رسائلك. الإرسال الجماعي دون موافقة يرفع معدّل الحظر والإبلاغ، وقد يؤدي إلى تقييد رقمك. راجع [الموافقة وإلغاء الاشتراك](/docs/security/consent-opt-out).

## قبل البدء

- رقم متصل (الحالة **connected**).
- لأرقام **Cloud API**: قالب معتمد (`APPROVED`) في Meta Business Manager.
- جهات اتصال مصنّفة بالوسوم أو [شريحة](/docs/guides/contacts) إن أردت استهداف فئة محددة.

## إنشاء حملة

1. افتح **Campaigns** واضغط **New Campaign**.
2. أدخل **اسم الحملة** واختر **الرقم** المرسِل.
3. اكتب الرسالة، أو استخدم أحد النماذج الجاهزة، أو مولّد الرسائل بالذكاء الاصطناعي.
4. لأرقام Cloud API اختر **القالب المعتمد** من القائمة (يظهر بجانب كل قالب لغته)، واملأ متغيراته.
5. حدّد **الجمهور**: كل جهات الاتصال، أو **شريحة**، أو وسمًا أو أكثر مفصولة بفواصل.
6. حدّد **التأخير بين الرسائل** بالثواني (من 1 إلى 60، الافتراضي 3).
7. اختر موعد الإرسال (بالتوقيت المحلي لمتصفحك) أو اتركه فارغًا للإرسال اليدوي.
8. راجع الملخّص واضغط إنشاء.

> **ملاحظة:** تُستثنى دائمًا جهات الاتصال المحظورة (Blocked) والتي ألغت اشتراكها (Opted out)، بصرف النظر عن الجمهور المختار.

### الشرائح

عند اختيار شريحة تستهدف الحملة جهات الاتصال المطابقة لقواعدها (كل القواعد، أو أيّها إن كانت الشريحة تستخدم **OR**). تُنسخ القواعد إلى الحملة عند إنشائها، فلا يغيّر تعديل الشريحة أو حذفها لاحقًا جمهور حملة مجدولة. ويُعاد حساب العدد عند بدء الإرسال، فتُضمَّن جهات الاتصال الجديدة المطابقة.

## المتغيرات

### أرقام واتساب ويب

تُرسل رسالتك نصًا، مع استبدال المتغيرات:

| المتغير | القيمة |
|---|---|
| `{{name}}` أو `{name}` | اسم جهة الاتصال (أو رقمها إن لم يكن لها اسم) |
| `{{phone}}` أو `{phone}` | رقم جهة الاتصال |
| `{{أي_مفتاح}}` أو `{أي_مفتاح}` | أي حقل مخصّص في متغيرات جهة الاتصال |

تُحذف متغيرات `{{…}}` التي لا قيمة لها من النص.

### أرقام Cloud API

تُرسل الحملة **دائمًا عبر القالب** بغض النظر عن نافذة الـ 24 ساعة. يصل العميل نص القالب المعتمد مع ملء متغيراته لكل جهة اتصال.

**متغيرات القالب.** بعد اختيار القالب يظهر حقل لكل متغيّر في نصّه: `{{1}}` و`{{2}}` … للقوالب المرقّمة، أو أسماء المعاملات (مثل `{{customer_name}}`) للقوالب المسمّاة. يقبل كل حقل نصًا ثابتًا والعناصر النائبة لكل جهة اتصال: `{name}` و`{phone}` وأي متغيّر لجهة الاتصال مثل `{city}`. قيمة الحقل الأول افتراضيًا `{name}`.

**لغة القالب.** تُحفظ اللغة الظاهرة بجانب القالب (مثل `ar` أو `en_US`) مع الحملة وتُستخدم كما هي. والحملات التي أُنشئت دون لغة محفوظة تجرّب `ar` ثم `en` ثم `en_US`.

> **تحذير:** املأ كل متغيرات القالب: ترفض Meta القالب المرسل بعدد معاملات مختلف، وتُحتسب الرسالة فاشلة. إذا لم تختر قالبًا، تستخدم WABEK قالب التسويق الافتراضي `marketing_offer` (بالمعامل `customer_name` ونص رسالتك في `offer_details`)، وقد لا يكون موجودًا على حسابك.

## التشغيل والإيقاف

| الإجراء | متى يتاح | الأثر |
|---|---|---|
| **Start** | `draft` أو `scheduled` أو `paused` | يبدأ الإرسال أو يستأنفه من حيث توقف |
| **Pause** | `running` | يوقف الإرسال مؤقتًا ويحفظ التقدّم |
| **Cancel** | `running` | يوقف الحملة نهائيًا (تصبح الحالة `failed`) |
| **حذف** | أي حالة عدا `running` | يحذف الحملة |

## الحالات

| الحالة | المعنى |
|---|---|
| `draft` | أُنشئت ولم تبدأ |
| `scheduled` | تنتظر موعدها |
| `running` | قيد الإرسال |
| `paused` | موقوفة مؤقتًا |
| `completed` | انتهت |
| `failed` | أُلغيت أو توقفت بسبب خطأ |

## الحملات الكبيرة

تُرسل الحملات الكبيرة على دفعات متتالية. بعد كل دفعة تُجدول الحملة نفسها لتكمل تلقائيًا خلال دقيقة، ويُحفظ التقدّم بعد كل رسالة، فلا تُرسل رسالة مرتين لجهة الاتصال نفسها. لا تحتاج إلى إبقاء الصفحة مفتوحة.

## متابعة النتائج

افتح الحملة لرؤية: إجمالي المستلمين، والمرسَل، والفاشل، وقائمة الرسائل مع سبب الفشل لكل رسالة. يصلك إشعار داخل لوحة التحكم عند اكتمال الحملة، ويُرسل [webhook الصادر](/docs/api/outgoing-webhooks) للحدث `campaign_completed`.

## إنشاء الحملات عبر الواجهة البرمجية

تقبل `POST /api/campaigns` (بجلسة لوحة التحكم) الحقول: `segment_id` (أو `contact_filter: {"segment_id": "..."}` / `{"tags": [...]}`)، و`template_name`، و`template_language`، و`template_variables` (مصفوفة القيم)، و`template_param_names` للقوالب ذات المعاملات المسمّاة (مصفوفة الأسماء بالترتيب نفسه). الحقل `scheduled_at` تاريخ ووقت بصيغة ISO 8601 مع فرق التوقيت (`2026-11-20T06:00:00.000Z`)؛ والقيمة بلا فرق توقيت (`2026-11-20T09:00`) تُقرأ بالمنطقة الزمنية في ملفك الشخصي، أو بتوقيت UTC.

## حدود الباقة

- لكل باقة عدد أقصى من الحملات شهريًا.
- كل رسالة في الحملة تُحتسب ضمن حد الرسائل الشهرية.

راجع [الباقات والحدود](/docs/getting-started/plans-limits).
