# جهات الاتصال والشرائح والاستيراد

## إضافة جهة اتصال

1. افتح **Contacts** واضغط **Add Contact**.
2. أدخل رقم الهاتف بالصيغة الدولية (مثل `966500000000`)، والاسم والبريد والوسوم اختياريًا.
3. احفظ.

> **ملاحظة:** لا يمكن تكرار الرقم نفسه داخل الحساب. إذا كان الرقم موجودًا يظهر الخطأ «Contact with this phone already exists».

تُنشأ جهات الاتصال أيضًا تلقائيًا عند وصول رسائل جديدة، أو عبر [الـ API](/docs/api/create-contact).

## الاستيراد من CSV

1. جهّز ملف CSV بسطر عناوين يحتوي على الأعمدة التالية:

| العمود | إلزامي | ملاحظات |
|---|---|---|
| `phone` | نعم | تُحذف أي رموز غير رقمية تلقائيًا |
| `name` | لا | حتى 200 حرف |
| `email` | لا | |
| `tags` | لا | افصل بين الوسوم بفاصلة منقوطة `;` |

```csv
phone,name,email,tags
966500000001,سارة,sara@example.com,vip;riyadh
971500000002,Omar,,new
```

2. في **Contacts** اضغط **Import CSV** واختر الملف.
3. تظهر رسالة بعدد السجلات المستوردة.

| القيد | القيمة |
|---|---|
| الحد الأقصى لحجم الملف | 5 ميغابايت |
| الحد الأقصى للصفوف في الملف الواحد | 20,000 صف |
| الصفوف بلا `phone` | تُتجاهل |

> **تحذير:** إذا كان الرقم موجودًا مسبقًا، فإن الاستيراد **يحدّث** سجله بقيم الملف. الأعمدة الفارغة في الملف قد تمسح القيم الحالية (مثل الاسم والوسوم). راجع ملفك قبل الاستيراد.

## التصدير

اضغط **Export CSV** في صفحة **Contacts** لتنزيل جهات الاتصال المعروضة.

## الوسوم

الوسوم هي الطريقة الأساسية لاستهداف الحملات. أضفها عند إنشاء جهة الاتصال أو من صفحتها، أو في عمود `tags` عند الاستيراد، أو عبر عقدة **Add Tag** في [الشات بوت](/docs/guides/chatbot).

> **ملاحظة:** الوسم حساس لطريقة الكتابة. استخدم صيغة ثابتة (مثل `vip` دائمًا وليس `VIP` أحيانًا).

## الشرائح (Segments)

الشريحة مجموعة محفوظة من الشروط تُحدَّث تلقائيًا.

1. افتح **Segments** واضغط **New Segment**.
2. أضف شرطًا أو أكثر:

| الحقل | العامل | مثال |
|---|---|---|
| Has Tag | contains | `vip` |
| Name | contains | `أحمد` |
| Phone | starts with | `966` |
| Opted Out | is | Yes / No |
| Is Blocked | is | Yes / No |

3. اضغط **Preview** لمعاينة عدد المطابقين، ثم احفظ.

## الحالات الخاصة

| الحالة | الأثر |
|---|---|
| **Blocked** | يُرفض الإرسال إليه من صندوق الوارد والحملات والـ API والتكاملات. |
| **Opted out** | ألغى العميل اشتراكه؛ يُرفض الإرسال إليه بالطريقة نفسها. راجع [الموافقة وإلغاء الاشتراك](/docs/security/consent-opt-out). |
| **AI Off** | لا يرد عليه مساعد الذكاء الاصطناعي، لكن يمكنك الرد يدويًا. |
