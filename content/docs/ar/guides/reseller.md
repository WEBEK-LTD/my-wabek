# نظام الموزّعين

يتيح نظام الموزّعين إعادة بيع باقات WABEK لعملائك بأسعار تحدّدها أنت، مع متابعة العملاء والأرباح من صفحة **Reseller**.

> **ملاحظة:** تتطلب هذه الميزة باقة تتضمن **Reseller**، وقد يلزم اعتماد حسابك كموزّع.

## 1. إنشاء باقة خاصة

1. افتح تبويب **Plans & Pricing** واضغط **Create Custom Plan**.
2. املأ الحقول:

| الحقل | الوصف |
|---|---|
| Base Plan | الباقة الأساسية التي تدفع ثمنها للمنصة |
| Plan Name | الاسم الذي يراه عميلك |
| Your Price / Month | سعرك الشهري |
| Your Price / Year | سعرك السنوي (اختياري) |

3. احفظ.

## 2. إنشاء رابط دعوة

1. افتح تبويب **Invite Links** واضغط **Create Invite Link**.
2. املأ الحقول:

| الحقل | الوصف |
|---|---|
| Label | اسم داخلي للرابط |
| Custom Code | رمز مخصّص (اختياري) |
| Plan | الباقة الخاصة المرتبطة بالدعوة |
| Free Trial Days | أيام التجربة المجانية |
| Discount % | نسبة الخصم |
| Max Uses | الحد الأقصى للاستخدام (فارغ = بلا حد) |

3. انسخ الرابط وشاركه. عندما يسجّل العميل عبره يُربط بحسابك كموزّع.

## 3. طريقة الدفع

في تبويب **Settings** اختر كيف يدفع عملاؤك:

| الخيار | الوصف |
|---|---|
| Through WABEK platform | يدفع العملاء للمنصة، وتُحوَّل أرباحك في كل دورة صرف |
| My own Stripe account | يدفع العملاء مباشرة إلى حساب Stripe الخاص بك بعد ربطه عبر OAuth |
| Both options | الخياران معًا |

لربط Stripe اضغط زر الربط واتبع خطوات Stripe. لا تطّلع WABEK على كلمة مرور Stripe أو مفاتيحه، ويمكنك فصل الحساب في أي وقت.

## 4. الصرف

في **Settings ← Payout Settings** حدّد جدول الصرف وطريقته (تحويل بنكي أو PayPal) وبيانات الحساب. يظهر سجل المدفوعات في تبويب **Payouts**.

## المتابعة

| التبويب | المحتوى |
|---|---|
| Overview | ملخّص العملاء والأرباح، واسترداد أكواد الهدايا |
| Referrals | قائمة العملاء المسجّلين عبر روابطك |
| Campaigns | إرسال حملة إلى عملائك |

> **تحذير:** أنت مسؤول أمام عملائك عن الأسعار والفواتير التي تحدّدها، خاصة عند استخدام حساب Stripe الخاص بك.
