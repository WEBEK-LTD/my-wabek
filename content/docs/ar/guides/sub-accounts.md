# الحسابات الفرعية

الحساب الفرعي حساب WABEK مستقل بلوحة تحكم وتسجيل دخول خاصين به، تنشئه وتديره من حسابك. يناسب الوكالات التي تخدم عدة عملاء، أو الشركات ذات الفروع.

## الفرق بين عضو الفريق والحساب الفرعي

| | عضو الفريق | الحساب الفرعي |
|---|---|---|
| البيانات | يعمل على بيانات حسابك | بيانات مستقلة ومعزولة |
| الأرقام | يستخدم أرقامك | يربط أرقامه الخاصة |
| تسجيل الدخول | بدعوة إلى حسابك | بريد وكلمة مرور خاصين بالحساب الفرعي |

> **ملاحظة:** تتطلب هذه الميزة باقة تتضمن **Sub-Accounts**، وإدارتها متاحة لصاحب الحساب فقط.

## إنشاء حساب فرعي

1. افتح **Sub-Accounts** واضغط إنشاء.
2. املأ الحقول:

| الحقل | الوصف |
|---|---|
| Full Name | اسم العميل أو الفرع |
| Email | بريد تسجيل الدخول (يجب ألا يكون مسجّلًا مسبقًا) |
| Password | 8 أحرف على الأقل |
| Max Instances | عدد الأرقام المخصّص (الافتراضي 1) |
| Max Contacts | عدد جهات الاتصال (`-1` بلا حد) |
| Max Messages/Month | الرسائل الشهرية المخصّصة (الافتراضي 1000) |

3. احفظ، ثم أرسل بيانات الدخول إلى صاحب الحساب الفرعي بطريقة آمنة.

يُنشأ للحساب الفرعي مفتاح API خاص به، ولا تختلط بياناته ببيانات حسابك أو بالحسابات الفرعية الأخرى.

## الإدارة

من الصفحة نفسها يمكنك تعديل حدود أي حساب فرعي أو تعطيله. التعطيل يسجّل خروج الحساب ويمنع الدخول إليه دون حذف بياناته.

> **تحذير:** اطلب من صاحب الحساب الفرعي تغيير كلمة المرور بعد أول تسجيل دخول.
