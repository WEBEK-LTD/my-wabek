# أمان المفاتيح

## كيف تُخزَّن المفاتيح

| | المفاتيح المسمّاة (`wbk_...`) | المفتاح الافتراضي |
|---|---|---|
| التخزين | يُخزَّن **ناتج التجزئة SHA-256** فقط، لا المفتاح نفسه | يُخزَّن في سجل الحساب ويمكن لصاحب الحساب إظهاره |
| العرض | مرة واحدة عند الإنشاء؛ بعدها يظهر أول 12 حرفًا فقط | يمكن إظهاره ونسخه من صفحة **API Keys** |
| الإلغاء | فوري من صفحة **API Keys** | — |
| تتبّع الاستخدام | يظهر تاريخ آخر استخدام | — |

- تُقارن المفاتيح بطريقة ثابتة الزمن.
- إدارة المفاتيح وعرضها متاحة لصاحب الحساب فقط، لا لأعضاء الفريق.
- لكل حساب فرعي مفاتيحه الخاصة، ولا يصل مفتاح حساب إلى بيانات حساب آخر.

> **ملاحظة:** لأن المفتاح الافتراضي قابل للإظهار، نوصي باستخدام **مفاتيح مسمّاة** في التكاملات، والاحتفاظ بالمفتاح الافتراضي للاختبار فقط.

## أفضل الممارسات

### لا تضع المفتاح في كود الواجهة

أي مفتاح يصل إلى المتصفح أو تطبيق الجوال يمكن لأي مستخدم استخراجه. استدعِ WABEK من خادمك فقط:

```
المتصفح ──► خادمك (يحتفظ بالمفتاح) ──► https://waabek.com/api/v1/...
```

| ❌ لا تفعل | ✅ افعل |
|---|---|
| وضع المفتاح في JavaScript الواجهة أو HTML | حفظه في متغيّر بيئة على الخادم |
| حفظه في مستودع Git | استخدام مدير أسرار أو ملف `.env` مستثنى من Git |
| إرساله في الرابط `?api_key=` | إرساله في ترويسة `X-API-Key` |
| مشاركة مفتاح واحد بين كل التكاملات | مفتاح مسمّى مستقل لكل تكامل |
| لصقه في تذاكر الدعم أو الدردشة | إرسال أول 12 حرفًا فقط عند الحاجة للتعريف به |

### تدوير المفاتيح

1. أنشئ مفتاحًا مسمّى جديدًا.
2. حدّث التكامل ليستخدم المفتاح الجديد، وتأكّد من نجاح الطلبات.
3. ألغِ المفتاح القديم من صفحة **API Keys**.

دوّر المفاتيح فورًا إذا غادر الفريق شخص كان يصل إليها، أو إذا اشتبهت في تسريبها.

### حماية نقاط الاستقبال لديك

- استخدم HTTPS دائمًا.
- أمّن روابط [Webhooks الصادرة](/docs/api/outgoing-webhooks) برمز سري في الرابط.
- طبّق حدًا لطلبات رموز التحقق على خادمك لكل رقم ولكل مستخدم.

## حساب WABEK نفسه

- فعّل [التحقق الثنائي](/docs/getting-started/create-account) لحسابك.
- راجع **Trusted Devices** دوريًا واحذف الأجهزة غير المعروفة.
- امنح أعضاء الفريق أقل دور يحتاجونه. راجع [الفريق والصلاحيات](/docs/guides/team-roles).
