# سياسات Meta وواتساب

استخدامك لواتساب عبر WABEK يخضع لسياسات Meta وواتساب، إضافة إلى [شروط WABEK](/legal/terms). هذه الصفحة ملخّص عملي، والمرجع الملزم هو نصوص Meta الرسمية:

- [WhatsApp Business Messaging Policy](https://business.whatsapp.com/policy)
- [WhatsApp Commerce Policy](https://www.whatsapp.com/legal/commerce-policy)
- [WhatsApp Cloud API documentation](https://developers.facebook.com/docs/whatsapp/cloud-api)

## القواعد الأساسية

1. **الموافقة أولًا:** لا ترسل رسائل يبدأها نشاطك إلا لمن وافق. راجع [الموافقة وإلغاء الاشتراك](/docs/security/consent-opt-out).
2. **نافذة الـ 24 ساعة:** خارجها لا يُسمح إلا بالقوالب المعتمدة. راجع [نافذة الـ 24 ساعة](/docs/getting-started/messaging-window).
3. **فئة القالب الصحيحة:** العروض والترويج = Marketing؛ تحديثات الطلبات والحساب = Utility؛ رموز الدخول = Authentication.
4. **احترام طلبات الإيقاف** فورًا.
5. **المحتوى المحظور:** تمنع سياسة التجارة بيع منتجات وخدمات معينة عبر واتساب. راجعها قبل إطلاق الحملات.
6. **هوية واضحة:** يجب أن يعكس اسم العرض (Display Name) نشاطك الحقيقي.

## جودة الرقم

تقيّم Meta كل رقم على Cloud API بحسب تفاعل المستلمين مع رسائله (الحظر، والإبلاغ، ومعدّل القراءة). يؤثر التقييم في عدد المحادثات التي يمكن للرقم بدؤها يوميًا.

| للحفاظ على الجودة | تجنّب |
|---|---|
| رسائل متوقعة ومفيدة للمستلم | الرسائل المتكررة أو العامة لقوائم كبيرة |
| تخصيص الرسالة باسم العميل وسياقها | إرسال الحملة نفسها مرات متتالية |
| توزيع الحملات الكبيرة زمنيًا | زيادة حجم الإرسال فجأة |
| إزالة غير المتفاعلين من قوائمك | مراسلة أرقام لم تتفاعل منذ مدة طويلة |

راقب تقييم الجودة في Meta Business Manager ← WhatsApp Manager.

## واتساب ويب

ربط الرقم عبر QR يستخدم واتساب ويب، وهو مخصّص للاستخدام الشخصي وفق شروط واتساب. الإرسال الآلي أو الجماعي عبره قد يؤدي إلى **حظر الرقم نهائيًا**، ولا تستطيع WABEK ولا Meta استرجاعه. استخدم Cloud API لأي إرسال واسع. راجع [ربط رقم واتساب](/docs/getting-started/connect-number).

## رسوم Meta

تفرض Meta رسومًا على بعض رسائل Cloud API حسب فئتها وبلد المستلم، وتُدفع لـ Meta مباشرة عبر حساب واتساب للأعمال الخاص بك، وهي منفصلة عن اشتراك WABEK. راجع صفحة الأسعار الرسمية لدى Meta لمعرفة الأسعار الحالية.
