# Quick replies

A quick reply is saved text you insert into the message box with one click, so your team answers faster and consistently.

## Create a quick reply

1. Open **Quick Replies** and click add.
2. Fill in the fields:

| Field | Required | Limit |
|---|---|---|
| Title | Yes | 200 characters |
| Message | Yes | 4,096 characters |
| Shortcut | No | 50 characters, for example `/hours` |
| Tags | No | Up to 20 tags |

3. Save.

## Using it in the inbox

1. Open a conversation in **Live Chat**.
2. Click the quick-replies button next to the message box.
3. Pick a reply. Its text is inserted into the message box; edit it if needed, then send.

The list is sorted by most used.

> **Note:** A quick reply is free text. On Cloud API numbers it cannot be sent to a customer outside the 24-hour window.

How many quick replies you can create depends on your plan.
