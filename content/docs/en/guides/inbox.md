# Inbox and team

The **Live Chat** page is the shared inbox for all your numbers. Incoming messages arrive in real time, and your teammates can reply from here.

## Switching between numbers

If you have more than one number, each number has its own inbox. Pick the number from the inbox list at the top of the page. WABEK remembers the last inbox you opened.

## Replying to a conversation

1. Select the conversation from the list.
2. Type your reply, or insert a **quick reply** with the quick-replies button. See [Quick replies](/docs/guides/quick-replies).
3. To attach a file, click the attachment button. The maximum file size is **16 MB**.
4. Click **Send**.

> **Note:** On Cloud API numbers, if the customer is outside the 24-hour window, free text is not sent and you see "Outside 24h window — customer must message first". Wait for the customer to message you, or reach them with an approved template. See [24-hour window](/docs/getting-started/messaging-window).

## Organizing conversations

| Property | Values |
|---|---|
| Status | `open`, `pending`, `resolved`, `spam` |
| Priority | `low`, `normal`, `high`, `urgent` |
| Assignee | The account owner, any team member, or a linked sub-account |
| Tags | Free-text list |
| Notes | Internal note up to 5,000 characters, never shown to the customer |

Use the status filter at the top of the list to show only open conversations (the default) or any other status.

## Working as a team

1. Invite teammates from the **Team** page. See [Team and roles](/docs/guides/team-roles).
2. For each member, choose which inboxes (numbers) they can access, or leave it empty to give access to all inboxes.
3. Assign each conversation to the member responsible for it.

**Team → Performance** tracks the messages each member has sent.

## Blocking a contact

On the contact's page, click **Block Contact**. Any send to a blocked contact from the inbox, campaigns, API endpoints and integrations is refused.
