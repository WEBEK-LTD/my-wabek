# Create an account

## Sign up with email

1. Open the sign-up page at `https://waabek.com/auth/register`.
2. Enter your name (at least 2 characters), email, and a password of at least **8 characters**.
3. Enter your WhatsApp phone number (optional now; required later to turn on two-factor authentication).
4. Click **Create account**.

> **Note:** Depending on platform settings, you may be asked for a verification code sent to WhatsApp during sign-up. Enter the 6-digit code to finish.

New accounts start on the Free plan. See [Plans and limits](/docs/getting-started/plans-limits).

## Sign up with Google or Facebook

On the sign-up page choose **Sign up with Google** or **Facebook**. The account is created with your social account's email.

## Sign up through a reseller link

If a reseller sent you an invite link (it contains `?code=`), the invite code is filled in automatically and the plan or trial attached to the invite is shown. Complete sign-up as usual. See [Reseller program](/docs/guides/reseller).

## Turn on two-factor authentication (2FA)

1. In **Settings → Profile**, add your WhatsApp number and save.
2. Open the **Security & OTP** tab.
3. Choose a mode:

| Mode | Behavior |
|---|---|
| Disabled | No code is required at sign-in. |
| Always | A WhatsApp code is required at every sign-in. |
| New Device Only | A code is required only when signing in from a new device. |

4. Click **Save Security Settings**.

Trusted devices are listed in the **Trusted Devices** tab, and you can remove any of them at any time.

> **Warning:** Never share a verification code with anyone. Support will never ask you for it.
